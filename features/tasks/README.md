# Tasks

Install `tasks` to add the task template and schema under `tasks/`. Markdown
records remain authoritative for status, priority, due dates, and completion.
Use inbox triage and weekly review skills to organize actions and open loops.

For a task report, inspect real records and add inline OpenUI to Markdown when
useful. A task-board Minion is optional app behavior, not a replacement store.
This package no longer ships the unsupported Mini-Project board. See the
[migration guide](../../docs/minions.md); preserve customized legacy views.
