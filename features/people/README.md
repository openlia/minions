# People

Install `people` to add relationship records under `people/`. Keep contact context,
important dates, explicit last-contact observations, and open loops in Markdown.
Do not infer contact activity from file modification times.

Use ordinary reports with optional inline OpenUI for relationship reviews. A
programmable follow-up app is optional and must not send messages without the
appropriate approval. This package no longer ships the unsupported Mini-Project
directory. See the [migration guide](../../docs/minions.md).
