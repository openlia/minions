# Travel

Install `travel` to add Markdown itineraries, reservations, packing lists, and
budget notes under `travel/`. Calendar entries and financial records retain their
own authoritative locations; link them rather than creating divergent copies.

Use inline OpenUI in trip reports when it helps. A travel Minion is optional for
genuine app behavior, not required to plan a trip. Bookings and external changes
remain approval-gated. This package no longer ships the unsupported Mini-Project
board. See the [migration guide](../../docs/minions.md).
