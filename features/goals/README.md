# Goals

Install `goals` to add the goal template and schema under `goals/`. Keep outcomes,
milestones, linked actions, and review dates in durable Markdown records.

Summarize inspected records in Markdown with optional inline OpenUI snapshots.
Add a goal-tracking Minion only when input handling or executable app behavior
is useful, without duplicating the goal store. This package no longer ships the
unsupported Mini-Project board. See the [migration guide](../../docs/minions.md).
