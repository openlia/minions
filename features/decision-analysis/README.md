# Decision analysis

Install `decision-analysis` for decision records under `decisions/` and a skill
for weighted scoring and sensitivity analysis. Preserve evidence, constraints,
uncertainty, and the person's decision authority in the record.

Use inline OpenUI in comparison reports when useful. A scoring helper and a
document view do not require a programmable app. This package no longer ships
the unsupported Mini-Project board. See the [migration guide](../../docs/minions.md).
