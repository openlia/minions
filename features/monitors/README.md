# Monitors

Install `monitors` to record watch conditions, sources, check frequency, observed
results, and recommended actions in `monitors/`. A frequency field is descriptive:
installing this feature does not create a schedule or send alerts.

A condition-monitor Minion is a natural optional extension for executable checks
and a dashboard. Verify actual schedule registration and permissions, preserve
observation provenance, and publish reviewable reports outside app internals.
This package no longer ships the unsupported Mini-Project view. See the
[migration guide](../../docs/minions.md).
