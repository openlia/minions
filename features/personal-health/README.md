# Personal Health 0.4

Open [Personal Health](openlia://minions/personal-health) for family profiles,
encounters, conditions, treatments, and measurements. The existing skill operates
on the same canonical Markdown records in `minions/personal-health/data/`.
Managed templates/schemas live in the app's `templates/`, outside instance data.

New installs contain no personal records. Triggers default off. Records retain
person boundaries, source evidence, and clinical/verification distinctions;
the dashboard is not a medical assessment.

See [app documentation](workspace/minions/personal-health/README.md) for setup,
structured entry, configuration, and verification.
